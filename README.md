# What is this?

It's a big project around pre-2005 Opel's Steering Wheel Controls and TID (or Text Information Display). It's not pretty yet but the idea is to have a companion in between the headunit, the TID and
the SWC.

## How to build it?

First, get PlatformIO. Then, use the target you need (ignore the buttons only target for now, they're WIP).
